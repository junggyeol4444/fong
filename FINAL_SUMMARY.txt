                            USAGE EXAMPLES
═══════════════════════════════════════════════════════════════════════

1. Generate Lyrics:
   $ python music_creator.py generate lyrics --genre pop --theme love \
     --rhyme-scheme ABAB --num-verses 2

2. Generate Music:
   $ python music_creator.py generate music --genre rock --key D \
     --bpm 140 --duration 64

3. Analyze Lyrics:
   $ python music_creator.py analyze lyrics data/raw/lyrics.txt

4. Analyze Music:
   $ python music_creator.py analyze music data/raw/song.mp3 \
     --extract-chords

5. Download from YouTube:
   $ python music_creator.py crawl "YOUTUBE_URL" --playlist \
     --genre pop --max-count 10

6. Synthesize Voice:
   $ python music_creator.py synthesize lyrics \
     --lyrics-file data/generated/lyrics.txt \
     --speaker-wav reference_voice.wav

7. Create Complete Song:
   $ python music_creator.py synthesize song \
     --lyrics-file lyrics.txt --midi-file music.mid

═══════════════════════════════════════════════════════════════════════
                          KNOWN LIMITATIONS
═══════════════════════════════════════════════════════════════════════

The following are intentional limitations of this MVP:

1. Voice Training
   - Uses pre-trained models (custom training requires GPU & time)
   - Training configuration setup provided for future implementation

2. MIDI to Audio Conversion
   - Requires external tools (FluidSynth, TiMidity++)
   - Standard for professional music production

3. Language Support
   - English only in MVP
   - Architecture supports multi-language extension

4. Chord Detection
   - Simplified algorithm for MVP
   - Advanced detection can be added later

5. Audio Quality
   - Depends on pre-trained TTS models
   - Acceptable for MVP, can be improved with custom training

═══════════════════════════════════════════════════════════════════════
                         INSTALLATION & SETUP
═══════════════════════════════════════════════════════════════════════

Quick Start:

1. Clone repository:
   $ git clone https://github.com/junggyeol4444/fong.git
   $ cd fong

2. Install dependencies:
   $ pip install -r requirements.txt

3. Download NLTK data:
   $ python -c "import nltk; nltk.download('punkt'); \
     nltk.download('averaged_perceptron_tagger')"

4. Verify installation:
   $ python verify_structure.py

5. Run tests:
   $ python test_system.py

6. Generate your first song:
   $ python music_creator.py generate lyrics --genre pop --theme love
   $ python music_creator.py generate music --genre pop --key C --bpm 120

For detailed instructions, see README.md or QUICKSTART.md
